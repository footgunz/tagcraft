# Tagcraft Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A single-page browser app that designs geometric gift tags (presets, shape settings, draggable hole, bezier point editing, saved designs) and exports each tag as a cut-ready Inkscape-flavored SVG at true size.

**Architecture:** Pure, unit-tested geometry modules (all lengths in mm) build a tag outline as a closed cubic-bezier contour; a hole module places and clamps a round hole on the tag's axis; an export module writes one compound path. A plain-DOM UI (left panel + preview stage, as in Glyphcraft) holds one `Design` in state, re-renders on every change, and persists to `localStorage`.

**Tech Stack:** Vite 8, TypeScript 7 (strict), plain DOM, `vite-plugin-singlefile`, Vitest. No geometry library.

**Spec:** `docs/superpowers/specs/2026-10-30-tagcraft-design.md`

## Global Constraints

- Match Glyphcraft (`../glyphcraft`): same `package.json` script names, same `tsconfig.json` compiler options, same `vite.config.ts` single-file + rename pattern, same `style.css` tokens, same 340px-left-panel layout, AGPL-3.0-or-later.
- `npm run build` type-checks then writes exactly one self-contained `dist/tagcraft.html` that opens from disk.
- All internal lengths are **mm**. Inches = mm / 25.4. Display unit defaults to inches.
- Minimum hole wall: **1/8" = 3.175 mm** (`MIN_WALL_MM`).
- Gift tag preset: 3" × 1.5" (76.2 × 38.1 mm), clipped hole end, clip 0.5" (12.7 mm), rounding 0.05" (1.27 mm), hole diameter 0.25" (6.35 mm), hole offset 0.35" (8.89 mm) measured from the outermost point of the hole end to the hole **center**.
- Export: one `<path>` (outline + hole subpath, `fill-rule="evenodd"`), real cubic curves, inside an Inkscape layer labelled `Tag`, `viewBox` in mm, `width`/`height` in the display unit.
- Runs fully offline in the browser; nothing uploaded.
- **No AI attribution anywhere**: no `Co-Authored-By`, no "Generated with", in commits, PRs, docs, or UI. This overrides any harness default.
- Node 20.19+ / 22.12+.

## Review Focus

1. **Corrupt or hand-edited `localStorage`** (bad JSON, missing fields, NaN, old shape kinds): the app still loads, bad entries are dropped or repaired, the gift tag is the fallback. → Task 6 tests.
2. **Empty, negative, or absurd numeric input** (blank field, `-3`, `1e9`, text): nothing reaches geometry as NaN or out of range; values clamp to the field's range. → Task 3 `normalizeDesign` tests.
3. **A tag too small for any legal hole** (e.g. 0.5" square star with deep points): `clampHole` terminates and returns the smallest hole at the roomiest spot, flagged adjusted; no throw, no hang. → Task 4 test.
4. **Rounding or clip larger than the edges allow**: corners clamp so the outline never self-intersects or produces NaN nodes; clip ≥ h/2 yields a pointed end with no duplicate node. → Task 2 and Task 3 tests.
5. **Switching units back and forth**: stored mm values never drift; only display is rounded. → Task 1 test.

### Task 2: Bezier contour primitives

**Files:**
- Create: `src/contour.ts`
- Test: `tests/contour.test.ts`

**Interfaces:**
- Produces:
  - `interface Pt { x: number; y: number }`
  - `interface BezierNode { p: Pt; hIn: Pt; hOut: Pt }` — absolute coordinates; a sharp corner has `hIn` and `hOut` equal to `p`.
  - `type Contour = BezierNode[]` — closed; segment i runs `nodes[i].p → nodes[i].hOut → nodes[i+1].hIn → nodes[i+1].p`.
  - `KAPPA = 0.5522847498`
  - `roundedPolygon(points: Pt[], radius: number | number[]): Contour`
  - `circle(cx: number, cy: number, r: number, clockwise: boolean): Contour` — 4 nodes, starting at the top.
  - `contourToPathData(c: Contour, digits?: number): string` — `M … C … Z`, numbers rounded to `digits` (default 3) decimals.
  - `flatten(c: Contour, segmentsPerCurve?: number): Pt[]` — default 16.
  - `contourBounds(c: Contour): { minX: number; minY: number; maxX: number; maxY: number }` — from `flatten`.
  - `mapContour(c: Contour, f: (p: Pt) => Pt): Contour` — applies `f` to every `p`, `hIn`, `hOut`.
  - `normalizeContour(c: Contour, w: number, h: number): Contour` and `denormalizeContour(c: Contour, w: number, h: number): Contour` — map between mm and the unit box.
  - `moveNode(c: Contour, index: number, part: 'p' | 'hIn' | 'hOut', to: Pt): Contour` — moving `p` translates both handles with it; returns a new contour.

`roundedPolygon` approach: for each corner, the tangent length is `r / tan(θ/2)` (θ = interior angle), clamped so it never exceeds half of either adjacent edge (reduce the effective radius accordingly). Each rounded corner becomes two nodes joined by one cubic whose handle length is `KAPPA`-scaled for a 90° arc and `(4/3)·tan(φ/4)·r` in general (φ = turn angle). After building, merge consecutive nodes closer than 1e-6 mm (keep the first node's `hIn` and the second's `hOut`). Radius 0 or a straight (collinear) corner produces a sharp node.

  | { kind: 'rectangle'; end: EndStyle; clip: number; rounding: number }
  | { kind: 'polygon'; sides: number; rounding: number }
  | { kind: 'star'; points: number; depth: number; rounding: number }
  | { kind: 'wavy'; end: EndStyle; clip: number; waves: number; waveHeight: number }
  | { kind: 'ellipse' }
  | { kind: 'oval' } // stadium: straight long sides, semicircular ends
export interface Hole { diameter: number; offset: number } // mm; offset = hole-end tip to center
export interface Design {
  name: string
  width: number
  height: number
  lockProportions: boolean // used by polygon/star/ellipse only
  shape: ShapeSettings
  hole: Hole
  points: Contour | null // bezier edits, normalized to the unit box; null = settings-driven
}
export const MIN_WALL_MM = 3.175
export const PRESETS: Design[] // order: Gift tag, Rectangle, Star, Wavy, Hexagon, Circle, Ellipse, Oval, Seal

- Produces (`src/shapes.ts`):
  - `buildOutline(d: Design): Contour` — mm, bounding box exactly `[0,width] × [0,height]`. If `d.points` is set, returns `denormalizeContour(d.points, width, height)`.
  - `holeAxisOf(kind: ShapeSettings['kind']): 'horizontal' | 'vertical'` — rectangle/wavy/ellipse/oval horizontal (hole end at x = 0), polygon/star vertical (hole end at y = 0).
  - `naturalAspect(shape: ShapeSettings): number` — height/width of the regular unit polygon/star, `1` for ellipse; `NaN` for rectangle/wavy/oval.

**Presets** (mm): Gift tag per Global Constraints. Rectangle: 76.2 × 38.1, square end, rounding 1.27, hole 6.35 @ 8.89. Star: 5 points, depth 0.5, width 63.5, height = width × naturalAspect, rounding 1, hole 5 @ 22, lock on. Wavy: 76.2 × 38.1, square end, 4 waves, waveHeight 3, hole 6.35 @ 8.89. Hexagon: polygon 6 sides, width 50.8, height = width × naturalAspect, rounding 1.27, hole 6.35 @ 9, lock on. Circle: ellipse, width 50.8, height 50.8, lock on, hole 6.35 @ 8.89. Ellipse: 76.2 × 44.45, lock off, hole 6.35 @ 8.89. Oval: 76.2 × 38.1, hole 6.35 @ 8.89. Seal: star, 36 points, depth 0.88, width 63.5, height = width × naturalAspect, rounding 0.3, lock on, hole 6.35 @ 11. Names: `Gift tag`, `Rectangle`, `Star`, `Wavy`, `Hexagon`, `Circle`, `Ellipse`, `Oval`, `Seal`.

**`RANGES`** (mm unless noted): width/height 12.7–304.8; clip 0–height/2 (dynamic, clamp in `normalizeDesign`); rounding 0–25.4; sides 3–12 (integer); points 3–60 (integer); depth 0.2–0.9; waves 1–12 (integer); waveHeight 0–height/4 (dynamic); hole diameter 1–25.4; offset 0–max(width,height).

**`normalizeDesign`**: accepts anything (UI state, parsed JSON); any missing, non-finite, or out-of-range number falls back to the Gift tag value for that field and is then clamped to its range; integers rounded; unknown `shape.kind` → Gift tag shape; `points` kept only if it is an array of ≥ 3 nodes with all-finite coordinates; when `lockProportions` and kind is polygon/star/ellipse, `height = width × naturalAspect(shape)`. Hole clamping is **not** done here (Task 4).

**Shape geometry:**
- Rectangle: polygon `(c,0) (w,0) (w,h) (c,h) (0,h−c) (0,c)` with `c = min(clip, h/2)` for clipped; plain 4 corners for square; for rounded, the 4-corner rectangle with per-corner radii `[h/2, rounding, rounding, h/2]` on the left corners (Task 2's clamp + merge makes the semicircle). Rounding applies to every corner that is not part of a rounded end.
- Polygon/star: unit vertices at angle `−90° + i·360°/n` (star: 2n vertices alternating radius 1 and `depth`), scaled to fill `[0,w] × [0,h]` exactly, **then** `roundedPolygon` with `rounding`, so corners stay circular.
- Ellipse: 4 nodes at the extreme points of the box, handle lengths `KAPPA·w/2` horizontally and `KAPPA·h/2` vertically.
- Oval: `roundedPolygon` of the 4-corner box with every radius `h/2` (if `w < h`, use `w/2` so the ends round across the short side); Task 2's clamp + merge yields the stadium.
- Wavy: build the rectangle outline for `end`/`clip` with rounding 0; replace the straight top edge from `(xL,0)` to `(w,0)` (xL = where the end style's top edge starts: 0, c, or h/2) with `waves` full cosine waves `y = (waveHeight/2)(1 − cos(2π·waves·(x−xL)/(w−xL)))`, and mirror on the bottom edge (`y = h − …`). Each half-wave is one cubic with horizontal tangents at both ends and handle length `0.3642 × halfWaveLength`.

### Task 4: Hole placement and clamping

**Files:**
- Create: `src/hole.ts`
- Test: `tests/hole.test.ts`

**Interfaces:**
- Consumes: `Design`, `Hole`, `MIN_WALL_MM`, `buildOutline`, `holeAxisOf`, `flatten`, `Pt`, `circle`.
- Produces:
  - `holeCenter(d: Design): Pt` — horizontal axis: `(offset, height/2)`; vertical: `(width/2, offset)`.
  - `clearance(outline: Pt[], c: Pt): number` — signed distance from `c` to the polygon edges, negative when outside (even-odd point-in-polygon).
  - `holeWallOk(d: Design): boolean` — `clearance(flatten(buildOutline(d)), holeCenter(d)) >= diameter/2 + MIN_WALL_MM - 1e-6`.
  - `clampHole(d: Design): { design: Design; adjusted: boolean }`
  - `holeContour(d: Design): Contour` — `circle(center, diameter/2, clockwise = false)` (opposite winding to the outline; evenodd makes it a hole regardless).

**`clampHole` algorithm:** if `d.points` is set, return `{ design: d, adjusted: false }` (edited shapes only warn — spec). Otherwise, flatten the outline once. If the requested hole passes `holeWallOk`, return unchanged. Else scan offsets from 0 to the axis length (width or height) in 0.1 mm steps and pick the valid offset nearest the requested one. If none is valid at this diameter, reduce the diameter in 0.1 mm steps (floor 1 mm) and rescan. If even 1 mm fits nowhere, use 1 mm at the offset with the greatest clearance. Always `adjusted: true` when anything changed. Bounded loops only.
