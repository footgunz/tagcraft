# Private fonts

Put personal-use fonts here: `.ttf`, `.otf` or `.woff` outline fonts, or `.svg`
single-line fonts. They show up in the app under *Your fonts* and are bundled by
`npm run build` and the dev server, but never by `npm run build:public`.

Everything in this folder except this README is ignored by git, so these fonts are
never committed or pushed.

License files go in `licenses/`, named `<font file name>-<anything>.txt`, and show
under **About this font** in the app.
